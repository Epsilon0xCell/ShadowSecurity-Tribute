A tribute, kept as a record

ShadowSecurity

“ShadowSecurity was an organization founded by me later shutdown after one year, this is a tribute.” That is the first line of my README, and I set it here the way it is written.

I add the line my README adds right after it: only the older version was shut down. What this repo keeps is the record of that older version, its projects, and the one idea I carried forward.

Founded by me. Closed after about a year.

What I built, and why it ended

I founded ShadowSecurity as a non-profit to build security tools and software that would help people protect themselves against cyber threats. I shut it down after about a year. My README says why in plain words: my own ambitious nature, and too many projects to manage at once.

The founding idea was Shadow-Linux: my favourite penetration testing GNU/Linux systems installed in one operating system, built on Bedrock Linux rather than forked with branding. That idea came first, before ShadowSecurity branched out, and it is the one thing I kept when the rest closed.

The lesson I wrote at the end of the README is the one I still hold: focusing on one core product is the key, and I tried to reinvent the wheel and do too much instead. I would rather this page quote that than soften it.

The honest centre: two files that are not written

I state this plainly, in the middle of the page, because it is the truest thing in the repo: Shadow-Linux.sh and Shadow-Mac.sh are placeholders. I have not written either script. Each file is only its header comment, and running either one does nothing and prints nothing.

There is no earlier code to restore. The original organization was deleted, and my README documents the restore attempt and why it failed: the restore menu sits inside the deleted organization, so I cannot reach it. I will not write a fake installer and call it the lost work.

A real run, at head a8510cc. Both files together, in full.
$ bash Shadow-Linux.sh
$ bash Shadow-Mac.sh
$ echo "exit: $?"

That run is the whole behaviour of this repo today: no output, exit 0. What the README says the scripts are meant to become, if I write them, is that Shadow-Linux will essentially become one giant regex script, and Shadow-Mac will set up a Mac with penetration testing tools and a configured out of box experience. Until then they stay empty on purpose.

A second name on the wall: KidsWhoHack

I founded KidsWhoHack to teach cybersecurity to kids. I built a course for it, then decided I was reinventing the wheel: text based content teaches this as well or better, and presentations and blogs reach more people and are easier to keep up. I shut KidsWhoHack down and kept writing text based content. My README puts its tribute inside this repo, so its name belongs on this wall too, on its own stone.
