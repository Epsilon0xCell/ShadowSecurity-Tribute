ShadowSecurity-Tribute

ShadowSecurity was founded by the author, ran for about a year, and closed. This repository is its memorial, built to keep its founding idea alive rather than to launch anything new. The board below reads the way the cupboard is checked: row by row, in the dark, by torchlight.

Open the repo What was learned

First row, the flagship

Shadow-Linux

The founding idea, and the one thing kept. The plan is a single script that brings the author favourite penetration testing distributions together inside one Bedrock Linux based system, in the README words, essentially one giant regex script that installs them into one operating system, with no branding of its own.

Note taped inside the door: Shadow-Linux.sh in the repository is an honest placeholder today, a header saying the script is not written yet. The site says that plainly instead of dressing an empty file as a finished installer. Shadow-Mac.sh is a placeholder the same way.

Second row, the smaller projects

Each project, and its true ending

Shadow-Live, a customised rescue distribution, set aside because it changed too little from RescueZilla, the distribution it forked.

Shadow-Windows and Shadow-Mac, both stopped over copyright worries. Shadow-Mac may return one day as a setup script rather than a system: a Mac set up with penetration testing tools and a configured out of box experience.

Shadow-Website, whose code is lost, with screenshots and video of the progressive web app surviving.

Shadow-Music, a SomaFM player fork, code also lost, video surviving.

Then the community names closed for lack of time: Shadow-Game, Shadow-Blog, Shadow-News, Shadow-Community, and Shadow-Storage.

Third row, the second memorial

KidsWhoHack

An organisation the author founded for teaching cybersecurity to children. After creating a course, he found text based content just as effective, and shifted to presentations, blogs, and text based lessons, which were easier to manage and reached more people. The organisation closed; its legacy lives on in the text based content he still creates.

Fourth row, the archive attempt

The door that deletion closed

The author tried to restore the original organisation code. The attempt is told straight in the README, with its links kept: GitHub on restoring a deleted repository, Stack Overflow on restoring a deleted organisation, and the GitHub changelog note on restoring deleted repositories. Because the whole organisation was deleted, the restore menu could not be reached, and that closed the door.

Note taped inside the door: the original organisation code could not be restored after deletion.

Final row

What the author says he learned

Ambition spread across too many projects is what ended them. He let his ambition get the better of him across many organisations, and learned that focusing on one core product is the key: one core product kept is worth more than a dozen started. The projects live on in other forms, and the needle still creeps, because the one script the organisation was founded for is still, deliberately, waiting to be written.

ShadowSecurity-Tribute: a memorial board under the stairs. The torch goes back on its nail; the meter keeps counting.
